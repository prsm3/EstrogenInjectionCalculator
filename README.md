# Introduction
Welcome to this project for a terminal-based application that calculates injection dosages for female hormone replacement therapy in transgender women.

This calculator is based on the [DIY HRT wiki](https://diyhrt.info/). For more comprehensive features, please use [their official calculator](https://transfemscience.org/misc/injectable-dose-vol-conc-conv/).

## Usage

Download the newest release from the [Releases Page](https://github.com/prsm3/EstrogenInjectionCalculator/releases) and run the executable.
