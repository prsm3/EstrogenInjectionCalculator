# Introduction
Welcome dear visitor. This is a project for a (currently terminal only) application to help you calculate your injection dosage for female hormone replacement therapy in transgender women.


It is based on the wonderful [DIY HRT wiki](https://diyhrt.info/).

This calculator only has the most basic features so far; please use [their official calculator](https://transfemscience.org/misc/injectable-dose-vol-conc-conv/) instead.
